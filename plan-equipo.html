06 — Stack técnico

Rápido de armar en pocas horas

Next.js+ Supabase+ Vercel+ Tailwind

Un solo lenguaje de punta a punta, deploy en minutos, y Supabase (patrocinador confirmado) da base de datos + auth + storage sin montar servidores.

Si el reto es sobre…Considerar
Landing / producto simpleNext.js + Vercel solo
IA / chat / agentesNext.js + Supabase + API de un LLM
Muy poco tiempoLovable / v0 / Bolt + Supabase
Automatización / flujosNext.js + Supabase + n8n/Make o funciones serverless
07 — Ideas en espera

Pendientes para decidir en equipo

Idea de proyecto

Visualizador de agentes de IA ("AI Town")

Mundo simulado tipo videojuego 2D donde cada personaje es un agente con su propia rutina (oficina, fiesta, dormir), visible en tiempo real desde un panel. Inspirado en "Generative Agents" (Stanford) y el proyecto open-source AI Town.

  • Mapa 2D (Phaser.js / PixiJS) con lugares y personajes
  • Cada agente decide su actividad vía LLM o reglas + horario
  • Memoria simple en Supabase para dar continuidad
  • Loop de tiempo (tick) que avanza el mundo
  • Panel lateral tipo feed con lo que hace cada agente

Factible como versión simplificada en 6-8h; la versión "completa" (memoria larga, personalidades ricas) es de semanas, no de un día. Se deja como pendiente hasta saber el reto real del kickoff.
